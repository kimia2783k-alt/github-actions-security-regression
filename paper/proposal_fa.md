# موضوع پیشنهادی مقاله

**عنوان:** تحلیل تجربی پسرفت‌های امنیتی در گردش‌کارهای GitHub Actions تغییر‌یافته توسط عامل‌های کدنویس هوش مصنوعی و ارزیابی یک سازوکار اعتبارسنجی مبتنی بر سیاست

**عنوان انگلیسی:** An Empirical Study of Security Regressions in AI-Agent-Modified GitHub Actions Workflows and Evaluation of a Policy-Based Validation Mechanism

**نوع پژوهش:** مقاله پژوهشی کاربردی، مبتنی بر تحلیل تجربی داده‌های عمومی و پیاده‌سازی نرم‌افزاری

**حوزه:** هوش مصنوعی عامل‌محور، امنیت سایبری، مهندسی نرم‌افزار

**مجله هدف اولیه:** Journal of Artificial Intelligence, Applications and Innovations (JAIAI)

---

## بیان مسئله

با گسترش استفاده از عامل‌های کدنویس مبتنی بر مدل‌های زبانی، این عامل‌ها علاوه بر کد برنامه، فایل‌های پیکربندی فرایند ساخت و انتشار نرم‌افزار (از جمله GitHub Actions) را نیز تغییر می‌دهند. موفقیت عملکردی این تغییرات (موفقیت build یا merge) لزوماً به معنای حفظ امنیت آن‌ها نیست. ممکن است سطح مجوزها افزایش یابد، کنترل‌های امنیتی حذف شوند، یا الگوهای خطرناک مانند استفاده نادرست از `pull_request_target` معرفی شوند.

## هدف پژوهش

1. شناسایی و طبقه‌بندی پسرفت‌های امنیتی در فایل‌های GitHub Actions تغییر‌یافته توسط عامل‌ها
2. مقایسه تغییرات عامل‌محور با تغییرات انسانی مشابه
3. طراحی و ارزیابی یک سازوکار اعتبارسنجی مبتنی بر سیاست برای تشخیص تغییرات ناامن قبل از ادغام

## سؤالات پژوهش

1. چه انواعی از پسرفت امنیتی در تغییرات Actions عامل‌محور رخ می‌دهد؟
2. آیا نرخ یا شدت این پسرفت‌ها با تغییرات انسانی تفاوت دارد؟
3. آیا اعتبارسنجی مبتنی بر سیاست می‌تواند این تغییرات را با دقت قابل قبول و نرخ هشدار اشتباه کنترل‌شده شناسایی کند؟

## روش اجرا

- استخراج درخواست‌های ادغام عمومی از مجموعه داده AIDev که فایل‌های `.github/workflows/` را تغییر داده‌اند
- تعریف تاکسونومی پسرفت و قواعد امنیتی مبتنی بر OWASP CI/CD Top 10
- پیاده‌سازی اعتبارسنج مقایسه قبل/بعد
- مقایسه با ابزار تحلیل ایستا (zizmor)
- ارزیابی با معیارهای Precision، Recall، FPR، نرخ پسرفت و هزینه اجرا

## نوآوری مورد انتظار

ارائه شواهد تجربی درباره پسرفت‌های امنیتی در تغییرات عامل‌های کدنویس و ارزیابی یک روش قابل‌بازتولید برای کاهش این پسرفت‌ها. تازگی دقیق پس از تکمیل مرور پیشینه نهایی می‌شود؛ فعلاً این عنوان به‌عنوان پیشنهاد اولیه ارائه می‌شود.
