# JAIAI Submission Checklist

Based on https://www.journalaiai.com/index.php/aiai/about/submissions

## Before upload

- [ ] Manuscript follows **JAIAI Template (English)** DOC (convert from `paper/manuscript/main.md`)
- [ ] Consistent American **or** British English (not mixed) — draft uses American
- [ ] Title concise; abstract self-contained
- [ ] Keywords present
- [ ] Figures/tables numbered and referenced in text
- [ ] References complete
- [ ] AI writing disclosure sentence included
- [ ] Conflict of interest statement included
- [ ] Funding / acknowledgments completed
- [ ] Permissions for any reused figures obtained (N/A for original plots)
- [ ] At least **three suggested reviewers** with emails
- [ ] Cover letter prepared
- [ ] Replication package link or zip ready
- [ ] All authors agree on author order (cannot change after acceptance per JAIAI)

## Files to upload (typical)

1. Manuscript (DOC from template)
2. Cover letter
3. Figures (high-res PNG/PDF) if separate
4. Supplementary / replication archive (optional but recommended)
5. Copyright / declaration form when requested by journal

## Author action required (cannot be automated)

- [ ] Register / log in to JAIAI OJS
- [ ] Fill author metadata
- [ ] Upload final DOC
- [ ] Sign copyright transfer / declaration
- [ ] Pay any APCs if applicable (verify on journal site)
- [ ] Respond to peer review

## Pre-submit quality gate (this repo)

- [x] Related work / gap documented
- [x] Study protocol written
- [x] Unit tests passing
- [x] Evaluation tables generated from pipeline
- [x] Threats to validity written
- [ ] Field AIDev sample scaled (recommended before final claim on prevalence)
- [ ] Supervisor review of title/authors/reviewers
